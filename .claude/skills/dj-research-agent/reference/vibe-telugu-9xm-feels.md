# Vibe profile — "Telugu 9XM Feels"

A reusable curation profile for building Telugu mixes that feel like the Hindi 9XM Feels / MTV Beats lane. Use this whenever the user asks for "warm romantic Telugu chill," "Telugu version of 9XM," "Telugu feel-good," "scooter-ride Telugu mix," etc.

The user validated this profile against the reference mix `mixes/VnN7nR-JHRc/` (Akarsh On Air — "30 Minutes of Chill Bollywood Mix"). This file encodes the thought process so a future agent can reproduce the same picks without re-deriving them.

## The mood in one paragraph

Late-night/early-morning, scooter-and-monsoon, college-love-story register. Lyric-led, singer-led, soft-to-mid-tempo melodies. Warm-romantic — *not* heartbreak-sad, *not* item-song loud, *not* devotional, *not* anthem-centerpiece. The kind of songs that play under a film's romantic montage, not under its mass-hero entry. BPM range as a *mood guide* (not a calculator): roughly 80–120.

## What's IN — track shape

A track fits this vibe if it has most of these:

- **Soft to mid tempo.** Slow ballad up to gentle mid-tempo. No EDM drops, no brass-heavy mass intros.
- **Singer-led, not composer-flex.** The voice carries the song — Karthik, Anurag Kulkarni, Sid Sriram (sparingly), Hariharan, Sunitha, Chinmayi, Yazin Nizar. Not full orchestra showpieces.
- **From a romantic / coming-of-age / friendship film** — Happy Days, Bommarillu, Anand, Godavari, Oohalu Gusagusalade, Geetha Govindam, Sita Ramam, Hi Nanna, Ye Maaya Chesave, Nuvvostanante Nenoddantana, Kushi.
- **Lyrics about love, longing, friendship, "first crush" warmth.** Not separation-grief, not rage.
- **Era sweet spot: 2001–2024,** with the densest band 2004–2018. Both the early-2000s "Anand/Godavari/Bommarillu" wave and the modern Sid-Sriram-led wave qualify.
- **Famous, mainstream-film catalog.** In Telugu, the genre essentially *is* film music — non-film indie barely exists at scale. Mainstream label releases (Aditya Music, Lahari, T-Series Telugu, Sony) are findable on pagalfree/raag/sensongs. Don't go hunting for "indie acoustic Telugu singer-songwriters" — the user has explicitly ruled that out.

## What's OUT — and why

The "warm-romantic chill" filter excludes a lot of otherwise-popular Telugu songs. Key exclusions:

- **Item / mass numbers.** Butta Bomma, Saami Saami, Oo Antava, Daakko Daakko Meka, Jai Balayya, Naatu Naatu. Wrong room.
- **Anthem-centerpiece songs even when "romantic."** Samajavaragamana (Sid Sriram version, ~165 BPM, hero-entry-coded), Kalaavathi (Sarkaru Vaari Paata — wedding-anthem feel), Urike Urike (Bheeshma — too mid-uptempo / chorus-anthem). These are "moment" songs, not "scooter ride" songs. They dominate any playlist they're in and break a chill mix's flow.
- **Heartbreak / grief ballads.** The Telugu equivalents of "Channa Mereya" / "Agar Tum Saath Ho." Warm-romantic only — *missing-someone* texture is fine, *they-are-gone-forever* texture is not. (User cue: "warm romantic, you caught the vibe.")
- **High-energy DSP/Thaman openers.** Even when romantic-themed, the production is loud-glossy-hooky and breaks the chill register.
- **Devotional / patriotic / mass-rural folk.** Different lane.
- **Tamil / Malayalam / Hindi songs.** This profile is **pure Telugu** unless the user explicitly asks for a regional share. (User cue: "ignore the Tamil Malayalam share as of now.")
- **Indie / non-film acoustic singer-songwriters.** Even if the user asks for "indie crossover," in Telugu this almost always means a YouTube-only, hard-to-source upload — and the user has confirmed the genre lives inside film. Stick with film. (User cue: "Don't search for independent acoustic singers unless they are very famous mainstream. In Telugu, most of the songs are famous from the movie only.")

## Singer-palette rules

- **Cap Sid Sriram at ~4 tracks per ~25-track set.** He's the modern face of the lane and it's tempting to lean on him, but a Sid-heavy list reads as monotone. Use him as a guest, not the host. (User cue: "bucket A was mostly just Sriram.")
- **Spread the voices.** Karthik (the original 9XM-Telugu voice — Happy Days, Bommarillu, Ye Maaya Chesave, Anand), Anurag Kulkarni (Pillaa Raa, Choosi Chudangaane, Hi Nanna's Ammaadi), Hariharan (Kushi-era), Sunitha (female lead on Oohalu Gusagusalade-era duets), Yazin Nizar, Javed Ali on Telugu, Chinmayi, Shreya Ghoshal Telugu, SPB Charan.
- **Composer signal:** Mickey J Meyer, K.M. Radha Krishnan, Kalyani Malik, early-Devi-Sri-Prasad-melody-side, Hesham Abdul Wahab, Vishal Chandrasekhar (Sita Ramam), Mahati Swara Sagar are the composers most aligned with this lane. Thaman / Anirudh / DSP-mass-side are usually NOT.

## Era weighting

For a ~25-track set, a balanced split looks like:

- **6–8 tracks from 2001–2009** (Anand 2004, Bommarillu 2006, Godavari 2006, Happy Days 2007, Kushi 2001, NVNV 2005, Nuvvu Nenu Prema 2006).
- **6–8 tracks from 2010–2017** (Ye Maaya Chesave 2010, Krishnam Vande Jagadgurum 2012, Oohalu Gusagusalade 2014, Cinema Choopistha Mava 2015, Nenu Local 2017, Cheliyaa 2017).
- **8–10 tracks from 2018–2024** (Geetha Govindam 2018, RX 100 2018, Chalo 2018, Taxiwaala 2018, Oh Baby 2019, Manmadhudu 2 2019, Uppena 2021, Sita Ramam 2022, Hi Nanna 2023).

Skew modern (post-2018) if the user is younger / more recent in their listening; skew 2000s if they grew up on Karthik's voice. Default 50/50 split between "modern Sid-Sriram-era" and "older Karthik/Hariharan-era."

## How to use this profile in a future session

When the user says something like "make me another Telugu chill mix" or "I want a Telugu version of [Hindi mix]":

1. **Read this file first.** Don't re-derive the philosophy.
2. **Confirm filters.** Check whether they want the same balance (era split, singer cap, regional purity) or a variation. The defaults are: pure Telugu, ~25 tracks, Sid Sriram capped at 4, 2001–2024 era band, BPM ~80–120, no item/anthem/heartbreak/indie/non-film.
3. **Build the candidate list** by pulling from "Anchor tracks" + filling out from "Bench tracks" + adding 3–5 fresh picks in the same lane.
4. **Apply the OUT filters** ruthlessly — when in doubt about whether a song belongs, ask whether it would work as a "scooter ride / morning coffee / late-night drive" track. If the answer is "no, this is a wedding-floor banger" or "no, this is a cry-yourself-to-sleep ballad," cut it.
5. **Show the list to the user before downloading.** They will prune and add filters.
