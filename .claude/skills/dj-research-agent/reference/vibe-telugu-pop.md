# Vibe profile — "Telugu Pop"

A reusable curation profile for Telugu mixes in the **pop** lane. Style-locked, not source-locked: Telugu Pop is *songs that sound poppy*, regardless of whether they came from a film soundtrack or an independent / non-film release.

Sister profiles:
- `vibe-telugu-feel-good-upbeat.md` — *mood* filter (bright/uptempo) across Tollywood
- `vibe-telugu-9xm-feels.md` — chill warm-romantic Telugu

Use this when the user asks for: "Telugu pop," "poppy Telugu," "Telugu pop playlist," "modern Telugu pop," or names tracks like Hi Nanna — Samayama / Kushi (2023) — Aradhya / Sid Sriram singles / Anirudh-Telugu pop singles / indie Telugu pop singles (Ram Miriyala pop side, Sahithi Chaganti, etc.).

## The mood in one paragraph

**Pop is a *style*, not a *source* and not a *mood*.** A Telugu Pop track is one with hooks, verse-chorus structure, polished commercial production, broad-appeal melody, and a contemporary pop vocabulary (synths, programmed drums, layered vocals, R&B/EDM/indie-pop-tinged production). Tempo is open — pop ballads (slow), mid-tempo pop, and uptempo dance-pop all qualify. The unifying thread is **production sensibility and song shape**, not BPM.

This is *not* the same as `feel-good-upbeat`. That profile is mood-locked (bright/upbeat) and includes non-pop styles like folk-fusion bangers and peppy semi-classical. Telugu Pop *excludes* those (wrong style) but *includes* slow pop ballads (right style, wrong mood for the upbeat profile).

## What's IN — track shape

- **Pop song shape**: clear hook, verse-chorus structure, 3–5 minute commercial length, vocal-forward mix.
- **Polished commercial production**: contemporary pop vocabulary — clean synths, programmed drums, sidechain pumping, vocal stacks/harmonies, R&B-tinged ad-libs, indie-pop reverbs, EDM drops where appropriate. Not orchestral, not folk-percussion-led, not raga-led.
- **Both film and non-film origins**. Film: Hi Nanna's "Samayama," Kushi (2023)'s "Aradhya," modern Anirudh-Telugu film pop, Hesham Abdul Wahab's pop side, Pawan Ch's pop side, GV Prakash's Telugu pop. Non-film: Ram Miriyala's pop singles, Sahithi Chaganti, Telugu indie-pop YouTube/Spotify-first artists, Sid Sriram's non-film singles when poppy.
- **Tempo-agnostic** — pop ballads count (slow), mid-tempo pop counts, uptempo dance-pop counts. The *style* is what makes it pop, not the BPM.
- **Modern era dominates** — Telugu Pop as a defined style is largely post-2015, heavy from 2018 onward. Earlier Tollywood is mostly orchestral / folk-fusion / Ilaiyaraaja-era and not "pop" in this sense, with a few exceptions (AR Rahman Telugu pop, late-90s Mani Sharma pop side, Karthik-era pop-rock).

## What's OUT — and why

- **Folk-fusion / mass-folk / Naatu-Naatu lane**. Folk-percussion-led, even if catchy. Wrong production style — that's folk, not pop.
- **Mass hero-entry anthems**. Srivalli (the mass version), Pushpa-mass, Nannaku Prematho mass intro. Wrong style, wrong sensibility.
- **Item / cabaret songs**. Different style register — they're closer to club/dance-mass than pop.
- **Devotional / patriotic / classical-traditional**. Different lane entirely.
- **Pure orchestral film romance from older eras** (Ilaiyaraaja-era Tollywood, MM Keeravani period dramas). Beautiful but not "pop" — they're orchestral film music.
- **Heavy semi-classical / Carnatic-led** (even if a pop singer like Sid Sriram is on it). The classical scaffolding makes it not-pop.
- **Boundary-case folk-fusion that *sounds* poppy but is built on folk percussion** (e.g. Saranga Dariya, Naatu Naatu) — out, despite the hooks. Production style decides.

## Singer / composer palette

**Anchor singers — pop-vocal aesthetic**: Sid Sriram (his pop side, both film & singles), Anirudh Ravichander (singer & composer — defines modern Telugu film-pop), Anurag Kulkarni's pop side, Hesham Abdul Wahab (singer & composer — Kushi 2023, Hi Nanna), Karthik (era pop-rock), Haricharan, Armaan Malik on Telugu, Yazin Nizar, Sanjith Hegde on Telugu, Sahithi Chaganti, Chinmayi (pop ballad side).

**Composers — pop production sensibility**: Anirudh Ravichander (Telugu work), Hesham Abdul Wahab, Pawan Ch, GV Prakash (Telugu), Vivek-Mervin, Leon James, Jakes Bejoy (pop side), Mickey J Meyer (pop-rock side), DSP (his pop side — Bommarillu / Nenu Sailaja, NOT his mass side).

**Composer signal — wrong lane**: Thaman's mass-anthem side, DSP's mass-hero side, Bheems Ceciroleo (folk-mass), Mani Sharma's mass-romantic side, Keeravani period/devotional, Ilaiyaraaja-era orchestral film.

**Indie / non-film Telugu pop artists**: Ram Miriyala (pop singles, not folk-mass), Sahithi Chaganti, Sanjith Hegde (Telugu collabs), and Spotify-first/YouTube-first Telugu indie-pop artists. This is a thinner pool than Hindi indie-pop but growing post-2020.

## Era weighting

Modern-skewed harder than the upbeat profile, because Telugu Pop as a *style* is largely a post-2015 phenomenon:

- **10–12 tracks from 2020–2025** (Anirudh-Telugu pop, Hi Nanna, Kushi 2023, modern indie pop, Andhra King Taluka pop side, Sid Sriram singles)
- **5–7 tracks from 2015–2019** (Geetha Govindam, Bhale Bhale Magadivoi pop side, Saaho Telugu, early Anirudh-Telugu)
- **2–4 tracks from 2005–2014** (Bommarillu pop tracks, Happy Days pop-rock side, Karthik-era pop, AR Rahman Telugu pop)
- **Pre-2005**: rare. Only if a track has a genuine pop-production aesthetic (some AR Rahman Telugu, some late-90s Mani Sharma pop). Default is to skip.

## Key boundary cases (read carefully)

These need a style-vs-not-style judgment:

| Track | Lane call | Reason |
|---|---|---|
| Inkem Inkem Kaavaale | In | Mid-tempo, but pop-ballad production, vocal-forward, hook-driven. Pop. |
| Samayama (Hi Nanna) | In | Slow but unambiguously pop-ballad shape. Pop. |
| Saranga Dariya | Out | Folk-fusion, folk percussion-led. Not pop. |
| Naatu Naatu | Out | Folk-mass even though hooky. Not pop. |
| Pushpa Saami Saami | Out | Item / mass-dance. Not pop. |
| Srivalli (Pushpa) | Borderline → Out | The romantic version is closer to pop, but the heavy folk arrangement keeps it out. |
| Kalaavathi (SVP, 2022) | Borderline | Sid Sriram pop-vocal but semi-classical scaffolding. Default out unless mix leans Sid-heavy. |
| Tillu Anna DJ Pedithe | Out | Folk-mass dance, not pop. |

| Old Ilaiyaraaja Telugu romance | Out by default | Orchestral, not pop. Even if catchy. |
| AR Rahman Telugu (Roja era) | Mostly out | Orchestral film with pop-modernist touches — call by track. |

**Avoid for harvesting**:
- *"Telugu Mass Beats"* / *"Pakka Beat"* — folk-mass / hero-entry, wrong style.
- *"Telugu Folk Hits"* — folk-fusion, wrong style.
- *"Telugu Bhakti"* — devotional, wrong lane.
- Old Ilaiyaraaja-era / pre-2000 Tollywood compilations — orchestral film, not pop.

## How to use this profile in a future session

When the user says "Telugu pop" / "poppy Telugu" / "modern Telugu pop":

1. Read this file.
2. Clarify with the user: pop-style across both upbeat and slow (this profile), or specifically the upbeat slice (use `vibe-telugu-feel-good-upbeat.md` instead)?
3. Harvest from Spotify's Telugu Pop / Hot Hits Telugu / Telugu Indie editorial playlists + per-album jukeboxes for the modern pop-leaning soundtracks listed above.
4. Apply the OUT filter aggressively — folk-fusion, mass, item, devotional, orchestral-period all out, **even if catchy**. The criterion is *production style*, not catchiness.
5. Default era weighting modern (2020+ leads, 2015–2019 fills, pre-2015 sparingly).
6. Apply popularity floor if user wants it (default: pre-2018 ≥ 2M, 2018+ ≥ 10M YouTube views — same as sister profiles).
7. Show list to user with YouTube URLs before sourcing audio.
